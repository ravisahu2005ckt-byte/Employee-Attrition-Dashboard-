# Employee Attributes & Project Analysis

## Project Overview

This project uses **Microsoft Power BI** to explore employee attributes
and project-related data through interactive reports and visualizations.
It is intended to make workforce information easier to understand and
support data-driven reporting.

## Objectives

-   Explore employee and project-related information.
-   Present data in a clear, visual format.
-   Make it easier to identify patterns and compare relevant employee
    details.

## Tools Used

-   **Microsoft Power BI** --- dashboard and report development
-   **Power Query** --- data preparation and transformation

## Project File

-   `project Emp Attri.pbix` --- Power BI project file. Download it and
    open it with Power BI Desktop to view the report.

## How to Open

1.  Download or clone this repository.
2.  Install **Power BI Desktop**.
3.  Open the `.pbix` file in Power BI Desktop.
4.  If Power BI requests access to a data source that is not included in
    this repository, reconnect the source before refreshing the report.

## Skills Demonstrated

-   Data analysis
-   Data preparation and transformation
-   Data visualization
-   Interactive reporting with Power BI
